Passwords should never be stored as plain text.


The most common safe storage method is hashing.

What is hashing?

One way conversion

A mathmatical function converts a Password into a fixed length string called a hash. It is one way and the original password cannot be recovered from the hash.

Rainbow tables

Attack method

A massive precomputed file of hash values for every possible password. attackers look up a stolen hash to instantly find the matching password.

Salting

Defense method

A unique random string is added to each password before hashing, even identical passwrods produce different hashes, completely defeating Rainbow tables lookups.

Pass-the-hash

advanced attack

The attacker steals the hash directly from storage, and uses it to authenticate - without ever knowing the original password.
